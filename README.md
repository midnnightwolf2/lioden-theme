# 🌸 Purple Hyacinth Cave - Lioden Profile Theme

A beautiful, cozy purple hyacinth-themed CSS stylesheet for Lioden profiles. Transform your den into a magical flowery sanctuary with elegant gradients, glowing effects, and whimsical animations!

## ✨ Features

### 🎨 Visual Design
- **Purple Hyacinth Theme**: Elegant purple, lavender, and violet color palette inspired by blooming hyacinth flowers
- **Floral Background**: Cozy hyacinth garden wallpaper with gentle shimmer effects
- **Corner Decorations**: Beautiful hyacinth flower decorations in the corner
- **Ornate Frames**: Decorative borders around profile elements and headshots

### 🌟 Effects & Animations
- **Glitter Shimmer**: Subtle sparkle overlay that twinkles across the page
- **Soft Glow**: Gentle purple glow effects on buttons and containers
- **Sway Animation**: Elements gently sway like flowers in a breeze
- **Bloom Animation**: Decorative elements bloom and pulse softly
- **Fireflies** (optional HTML): Add magical floating fireflies to your profile

### 🎯 Styled Elements
- Navigation buttons with gradient backgrounds and hover effects
- Panels and containers with transparent purple overlays
- Alert boxes with themed colors and borders
- Buttons with glow effects and smooth transitions
- Tables with alternating row colors and rounded corners
- Cave grids and mound grids with themed styling
- Profile headshots with ornate decorative frames

## 📦 Installation

### For Lioden Profile Pages

1. **Download the CSS file**:
   - Download `purple-hyacinth-cave.css` from this repository

2. **Copy the CSS**:
   - Open the CSS file and copy all its contents

3. **Apply to your Lioden profile**:
   - Go to your Lioden profile settings
   - Navigate to the custom CSS section
   - Paste the copied CSS code
   - Save your changes

4. **Enjoy your new theme!** 🎉

### Optional: Add Fireflies HTML

The CSS file includes an optional HTML fragment for animated fireflies. Look for the "FIREFLY FRAGMENT" section in the CSS file (around line 2184) and follow the instructions to add it to your profile HTML.

## 🎭 What This Theme Does

### ✅ Applies to Your Profile:
- Beautiful purple hyacinth color scheme
- Gradient backgrounds and borders
- Glowing effects on buttons and containers
- Smooth animations and transitions
- Decorative frames around headshots
- Themed navigation elements
- Styled tables, panels, and content areas
- Shimmer and sparkle overlays

### ❌ What It Doesn't Do:
- **Does NOT replace your banner images** - Your custom banners will show normally
- **Does NOT replace your cave images** - Your cave backgrounds remain unchanged
- **Does NOT show other users' images** - Theme is purely decorative styling
- **Does NOT require any specific images** - Works with any profile content

## 🎨 Customization

The theme is designed to work universally on any Lioden profile. All styling is decorative and enhances your existing content without replacing it.

If you want to add your own custom banner or cave images as personal modifications, see **[CUSTOMIZATION-GUIDE.md](CUSTOMIZATION-GUIDE.md)** for instructions.

## 🛠️ Technical Details

### Browser Compatibility
- Works on all modern browsers (Chrome, Firefox, Safari, Edge)
- Uses CSS3 features including gradients, animations, and transforms
- Gracefully degrades in older browsers

### CSS Features Used
- CSS Variables for consistent theming
- Keyframe animations for smooth effects
- Pseudo-elements (::before, ::after) for decorative layers
- Flexbox for responsive layouts
- Border-image for ornate frames
- Multiple background layers for depth

### Performance
- Optimized animations using transform and opacity
- Hardware-accelerated animations where possible
- Minimal performance impact on page load
